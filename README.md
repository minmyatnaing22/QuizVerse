# QuizVerse

## Overview
QuizVerse is a web application that helps Myanmar Grade 12 students practice objective questions across six subjects.

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js + Express
- Database: SQLite (MVP)

## Project Structure
- frontend/
- backend/
- database/
- docs/

## Git Workflow
1. Clone the repository.
2. Create your own feature branch.
3. Commit and push your changes.
4. Ask for a review before merging into `main`.
